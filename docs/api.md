# TruthLens REST API Specification (v1)

Base URL: `/api/v1`

All responses follow the unified envelope:
```json
{
  "success": true,
  "data": { ... },
  "error": null,
  "request_id": "8fa538e1-d419-4824-a2fa-10113fba3594"
}
```

---

## 1. Authentication

### `POST /auth/register`
Register a new user account. The first registered user is automatically provisioned as `ADMIN`.
- **Request Body**:
  ```json
  {
    "email": "analyst@journalism.org",
    "password": "SecurePassword123!"
  }
  ```
- **Response**: `200 OK`
  ```json
  {
    "success": true,
    "data": {
      "access_token": "eyJhbGciOiJIUzI1NiIs...",
      "token_type": "bearer",
      "expires_in": 86400
    },
    "error": null,
    "request_id": "..."
  }
  ```

### `POST /auth/login`
Authenticate existing user credentials.
- **Request Body**:
  ```json
  {
    "email": "analyst@journalism.org",
    "password": "SecurePassword123!"
  }
  ```

### `GET /auth/me`
Retrieve profile of currently authenticated user. Requires `Authorization: Bearer <token>`.

## 2. Analysis Endpoints

### `POST /analysis`
Execute credibility assessment on news text or headline.
- **Request Body**:
  ```json
  {
    "headline": "Federal Reserve Holds Rates Steady",
    "text": "The Federal Reserve concluded its policy meeting Wednesday by maintaining its benchmark interest rate...",
    "input_type": "article"
  }
  ```
- **Response**: `200 OK`
  ```json
  {
    "success": true,
    "data": {
      "id": "23a1a4b3-c159-4d69-b5cf-72b166827a51",
      "title": "Federal Reserve Holds Rates Steady",
      "input_type": "article",
      "language": "en",
      "status": "COMPLETED",
      "prediction": {
        "label": "LIKELY CREDIBLE",
        "raw_score": 0.7259,
        "calibrated_probability": 0.99,
        "confidence": 98.0,
        "confidence_level": "High",
        "model_agreement": "High",
        "ood_score": 0.358,
        "model_scores": {
          "logistic_regression": 0.5393,
          "linear_svm": 0.9424,
          "gradient_boosting": 0.9999,
          "transformer": 0.5185
        },
        "summary": "The models observed linguistic discipline, standard journalistic attribution...",
        "limitations": "This assessment is generated by statistical models..."
      },
      "claims": [ ... ],
      "evidence": [ ... ],
      "explanation": { ... }
    }
  }
  ```

### `POST /analysis/url`
Safely fetch webpage content from URL (with SSRF protection) and perform credibility assessment.
- **Request Body**:
  ```json
  {
    "url": "https://www.reuters.com/world/us/fed-holds-rates-2024"
  }
  ```

### `GET /analysis/{analysis_id}`
Retrieve full analysis result by UUID.

### `DELETE /analysis/{analysis_id}`
Delete analysis record. Enforces user isolation (users can only delete their own records).

### `GET /analysis`
List analyses with pagination and query filters:
- Parameters: `page`, `page_size`, `assessment`, `input_type`, `search`

### `POST /analysis/{analysis_id}/feedback`
Submit user review on assessment utility.

---

## 3. Models & Administration

### `GET /models`
List registered models and actual evaluation metrics (accuracy, precision, recall, F1, Brier score, ECE, confusion matrix).

### `GET /admin/analytics`
Retrieve aggregate usage statistics, input distributions, and average confidence.

### `POST /admin/models/{model_id}/status`
Promote or roll back model lifecycle status (`STAGING` -> `PRODUCTION`).

### `GET /admin/audit-logs`
Inspect administrative action trail.

---

## 4. Health & Diagnostics

### `GET /health/live`
Process liveness check (`200 OK`).

### `GET /health/ready`
Subsystem readiness probe validating database connection and ML model artifact presence.
